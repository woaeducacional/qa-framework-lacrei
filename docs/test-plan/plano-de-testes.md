# Plano de Testes

## Objetivo

Definir a estratégia de validação da plataforma Lacrei Saúde, garantindo qualidade, estabilidade, acessibilidade e boa experiência para o usuário.

---

## Escopo

Serão contemplados:

- Cadastro de usuário
- Login
- Recuperação de senha
- Busca por profissionais
- Navegação
- Responsividade
- Performance
- Acessibilidade

---

## Tipos de Teste

### Testes Funcionais

- Cadastro
- Login
- Busca
- Recuperação de senha

### Testes Não Funcionais

- Performance
- Responsividade
- Acessibilidade

---

## Critérios de Aceite

Todos os testes críticos devem ser aprovados.

Não poderá existir bug crítico aberto.

Performance mínima Lighthouse:

- Performance ≥ 90
- Accessibility ≥ 95
- Best Practices ≥ 90
- SEO ≥ 90
