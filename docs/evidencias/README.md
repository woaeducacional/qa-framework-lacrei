# Evidências de Testes

Esta pasta armazenará todas as evidências produzidas durante a execução dos testes.

## Estrutura

- Capturas de tela (Screenshots)
- Vídeos de execução
- Relatórios do Cypress
- Relatórios do Lighthouse
- Logs de execução
- Evidências de bugs

## Objetivo

Garantir rastreabilidade dos testes executados e facilitar auditorias, revisões e validações antes da aprovação para produção.
